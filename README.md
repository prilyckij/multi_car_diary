# 🚗 Multi-Car Diary — управляй всеми своими автомобилями в одном месте

> «Один дневник — все твои машины»

**Multi-Car Diary** — это набор консольных приложений для ведения учёта обслуживания нескольких автомобилей.  
Программа позволяет создавать профили для каждого автомобиля и отслеживать ремонты, замены масла, напоминания и пробег для каждого из них.

## 🚀 Особенности
- 🚙 Управление несколькими автомобилями (добавление, удаление, переключение).
- 📝 Для каждого авто: марка, модель, год, VIN, пробег.
- 🔧 Учёт ремонтов и обслуживания (дата, пробег, описание, стоимость).
- 🛢️ Отслеживание замен масла с автоматическим расчётом следующей замены.
- 🔔 Напоминания по каждому автомобилю.
- 📊 Статистика по каждому авто и общая.
- 💾 Автосохранение в JSON-файл (`cars.json`).
- 🎨 Цветной вывод в терминале и интерактивное меню.

## 🛠️ Установка и запуск

Для каждого языка — минимальные зависимости (в основном стандартные библиотеки).

| Язык       | Зависимости              | Команда запуска                         |
|------------|--------------------------|-----------------------------------------|
| Python     | стандартная библиотека   | `python multi_car_diary.py`             |
| Go         | стандартная библиотека   | `go run multi_car_diary.go`             |
| Ruby       | стандартная библиотека   | `ruby multi_car_diary.rb`               |
| Java       | стандартная библиотека   | `javac multi_car_diary.java && java multi_car_diary` |
| JavaScript | Node.js, никаких         | `node multi_car_diary.js`               |
| C#         | .NET (или mono)          | `dotnet run`                            |
| Rust       | `serde`, `serde_json`    | `cargo run`                             |
| PHP        | стандартная библиотека   | `php multi_car_diary.php`               |

> Все программы создают файл `cars.json` в той же папке.
